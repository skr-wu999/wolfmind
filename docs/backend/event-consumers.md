# 已提交事件的四组消费契约

2026-10-14，所有者批准接入 cg-projection / cg-broadcast / cg-insight；cg-agent 保留既有任务围栏。
使用同一 Redis Stream，各组位点、消费者身份、失败计数、阻塞记录和目录独立。

## 职责与数据所有权

| 组 | 输入 | 成功条件 | 数据所有权 |
| --- | --- | --- | --- |
| cg-agent | 对局事件 | 调度任务可靠保存或窗口已失效 | 回合任务/预算；不执行归档或统计 |
| cg-projection | 对局事件 | SQLite 事件提交、查询投影更新；终局完整性核对后才能缩短 TTL | game_events、games 的归档水位/完成标记、Redis 查询投影 |
| cg-broadcast | 对局和房间事件 | 已经过权限过滤并完成本机推送处理 | WebSocket 呈现；掉线连接依靠重连补偿 |
| cg-insight | 对局事件及终局派生数据补做 | 结果/回放索引和统计明细、累计值在 SQLite 事务中提交 | game_history、statistics；不得提前改归档水位或缩短 TTL |

Redis 模式关闭进程内直接广播，提交后消费 Stream；内存模式保留直接广播。
模型流式发言预览仍是呈现通道，不进入领域事件组。
广播 ACK 不等于所有客户端收到；连接失败不能阻塞整个组，其他处理异常保留待补做消息。

## 归档服务与重试

正常 cg-projection 和定时归档补漏调用同一归档服务，复用事件写入、连续版本/重放校验、
完成标记与保留期更新。未归档流不自动过期，已有 SQLite→Redis 完整终局恢复继续保留。
各组按单局版本顺序处理；重复投递通过版本/事件 ID、统计单局唯一行和累计重算幂等。
每组每局使用独立 Redis 租约保护未确认前缀；正常 ACK/失败/关闭释放，进程失联后租约到期。
删除目录前原子核对流尾已被当前确认水位覆盖，避免把刚到达的新事件一并删除。
数据库/连接等暂时失败重试并暴露积压；无法解码的坏事件三次后隔离并阻塞该组该局，其他组/对局继续。
重启使用新消费者身份，接管超过空闲阈值的未确认消息。每组单线程保持本实例内单局顺序。
各组发现目录独立，某组终局退出不删除其他组待办目录。
派生组积压遇到已过期终局流，可从完整 SQLite 归档补做；广播不重发过期历史，靠快照/重连同步。

## 统计与结果

使用 database-schema.md 已定义的 game_history/statistics 与部分唯一索引，不引入新业务表。
单局统计明细和累计重算同一事务提交；禁止累计值直接加一。GLOBAL/ALL 不属于某个阵营，
只记录对局数/轮次/存活数，胜场为 0；阵营胜率从 games.winner 汇总。ROLE 每局每角色计一次，
AGENT 使用现有决策归档里的 agent_id（当前为 p_N），PLAYER 使用真人 controller.refId。
AI 成本仅统计已归档的决策痕迹；终局后的痕迹补到达需触发幂等重算，不能声称没有记录的 token 为已测量用量。
终局后的 AGENT_TURN_FINISHED 归档触发补算请求；收据 UUID compare-and-delete 防止并发新请求丢失。
每 30 秒从 SQLite 检查缺失 GLOBAL 明细和晚到痕迹，补发 Redis 请求，弥补痕迹提交与通知之间的崩溃窗口。
SUMMARY 只保存终局完整状态与关键事件版本；角色/隐藏信息继续由已有 API 可见性策略控制。
本轮只保存终局完整 SNAPSHOT，不宣称已归档全部间隔快照；阶段历史可由事件确定性重建。

## 运行设置

Redis 模式三个新增消费者默认启动（wolfmind.consumer.enabled=true），其他模式没有这些线程。
wolfmind.consumer.claim-idle-ms 默认 60000，控制新增三组接管空闲阈值；cg-agent 保留原 60 秒阈值。
关闭 consumer.enabled 只用于受控测试/排障，会停止 Redis 广播/正常归档/统计及统计补漏；不能作为生产运行方式。
archive.enabled 控制定时归档补漏，不关闭正常 cg-projection。广播当前为单后端部署，本轮不实现跨后端 WebSocket 扇出。

## 验收

真实 Redis DB15 + SQLite：四组独立位点、重启接管、重复投递、坏消息隔离、数据库恢复重试、
终局归档/统计幂等、归档完成标记不被统计覆盖、目录互不删除、历史过期补做及广播权限/重连。
回归既有调度预算、超时围栏、未归档 PERSIST、SQLite 恢复和整局回放；模型使用固定替身。
