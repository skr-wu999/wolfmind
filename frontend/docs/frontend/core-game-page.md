# 核心游戏页：本地 UI 实现与验收

**当前布局已于 2026-10-13 更新为游戏桌、实时群聊与阶段操作栏，说明及最新验证见 [核心群聊改版](core-game-chat.md)。下面保留早期本地原型的历史记录，接口未接入等描述不代表当前在线集成状态。**

## 范围与入口

路由 `/games/:gameId`，本地入口 `/games/demo`；大厅下方提供「体验核心游戏页 · 本地演示」。非 demo 标识展示未接入提示、重试和返回大厅，不会误读本地数据为在线对局。

依据用户提供的核心页图片与 V1.0 UI / UX 说明，保留左侧营火桌、右侧信息/行动区和底部身份栏。图片中的十二人、日间投票同时可操作和夜景白天讨论，按说明及现有经典九人契约调整为九席、独立讨论/投票阶段、日夜场景随展示阶段变化。

这是 UI 原型验收，不是在线多人、AI 模型或规则引擎验收。不会调用 REST、WebSocket 或 LLM；不会启动真实对局。当前房间开局按钮仍等待在线接入。

## 展示状态与交互

所有场景使用同一路由和同一组座位。顶部「本地演示 · 场景」是原型操作，不对应真实游戏命令或身份切换。

| 场景 | 主要交互与状态 |
| --- | --- |
| 白天 AI 发言 | 分段公开文本、当前座位突出、发言顺序；预览未结束不进入正式记录 |
| 白天本人发言 | 1..500 字纯文本；Ctrl+Enter/按钮提交；错误保留输入；成功进入公开发言记录 |
| 白天投票 | 权限目标列表和桌面同步单选、弃票、二次确认；提交后禁用，不推算票数或出局 |
| 天亮 | 公开平安夜结果；「继续演示讨论」显式切换场景 |
| 投票结算 | 固定示例计票与公开放逐结果；不能继续投票 |
| 天黑/夜间结算 | 同一村庄切换夜景，等待阶段更新，不展示其他职业行动进度 |
| 预言家 | 合法目标、确认查验、本人结果弹窗与私有记录；示例结果明确标注，不推断他人身份 |
| 狼人 | 仅阵营快照包含队友标记与密谈；密谈不进入公开消息；袭击确认后等待结算 |
| 女巫 | 两药剩余、适配器指定救助对象、毒药选择、二次确认/不用药；本示例一药完成后锁定其他药剂 |
| 村民/普通猎人 | 无夜间目标选择，只有等待与公开记录 |
| 猎人触发 | 即使本人出局，投影明确授权时可选目标或放弃；提交后等待公开结算 |
| 游戏结束 | 固定示例胜负与全员公开身份、重新体验入口；无未实现的回放/分析链接 |
| 守卫 | 扩展 UI 预览，排除上一夜示例目标；`GUARD_PREVIEW` 不对应当前九人规则或线上 API |

投票候选、技能目标、资源和能力均从适配器的 `permissions` 读取。页面不从角色/存活状态推算合法目标，也不根据头像、发言或技能提交推算阵营、出局或胜负。

## 状态、隐私和恢复边界

- 加载中展示九席骨架及明确说明，倒计时不使用假值。读取失败保留重试/示例入口。
- 提交时禁用重复操作。失败保留输入并读取新快照；路由变化和断线使旧响应失效，旧对局不能覆盖新页面。
- 倒计时来自适配器 `deadline` 与 `serverNow`，只更新显示。归零禁用输入提交并提示等待，不自动提交 `SKIP` 或切换阶段。实际截止校验仍在适配器。
- `version` 随完成事实递增；AI 文本预览不提升版本，完成发言仅记录一次。取消订阅时清理预览计时器。
- 公共玩家数组在对局中不包含未授权职业；狼人场景仅披露队友，结束场景才披露全员。日志只读取 `records`，技能记录只读取 `privateRecords`；狼人密谈单独读取 `wolfMessages`。这不是生产环境的授权过滤实现。
- 「模拟断线」保留画面及表单，禁用行动；「重新同步」从适配器恢复场景和权限，再订阅。无自动重发行动。
- `sessionStorage` 的 `wolfmind.demo.game.v1` 保存场景、截止时间、完成状态和当前视角的记录。重载不会重置为白天或续期倒计时；存储不可用时退回内存。此数据仅用于本机示例，不能作为服务端身份凭据。
- 场景切换是显式原型重置，会清空选择和草稿。真实对局不会提供此控件。

## 视觉决定

读取为真人与 AI 混合对局的像素村庄游戏界面，ENERGY 2 / RHYTHM 2 / MOTION 1。

| 决定 | 目的 |
| --- | --- |
| 木框、纸面、森林与陶土橙 | 延续图片与既有村庄的材质和交互身份 |
| 左桌右行动，底部本人身份 | 游戏桌固定，当前阶段的操作在同一位置出现 |
| 固定编号圆桌，手机改为双列座位 | 保持可识别座位，窄屏不压缩昵称和触摸区域 |
| 中文黑体，编号/时间使用现有 Pixelify | 正文可读，游戏装饰信息延续像素字体 |
| AI/你/淘汰/发言标签 | 每个标记代表真实示例状态，不凭颜色或动物头像推断身份 |
| 当前选择陶土橙，自己金棕边框 | 区分行动目标、当前发言与本人位置 |
| 分段发言，无永久跳动 | 明确公开发言仍在生成，不干扰目标选择与阅读 |
| 不同视角的独立记录面板 | 明确公开、本人、狼人阵营消息的展示边界 |
