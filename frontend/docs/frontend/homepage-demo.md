# 首页 Demo 设计与验证

## 方向

面向狼人杀玩家的像素卡通村庄。ENERGY 2 / RHYTHM 2 / MOTION 3。

本轮按用户反馈保留完整像素村庄，精简界面浮层。阅读顺序为品牌、左侧标题与游戏入口、村庄、右侧辅助信息。首页原型现已迁入 `frontend/` 的 `/` 路由；[主项目架构设计](../../../DESIGN.md)和共享契约仍位于项目根目录的文档体系中。迁移保留此视觉方向。

| 决策 | 原因 |
| --- | --- |
| 保留房屋、远山、树木、广场与 NPC | 村庄是首页的主体，界面优化不重新制作场景。 |
| 左侧只保留品牌标题、一句副标题和开始游戏 | 建立明确的阅读顺序，入口不再依赖右侧介绍。 |
| 右侧约 300px 高的村庄档案卡 | 减少大口号和碎片信息，保留说明、模式和玩法入口。 |
| 底部中央悬浮 HUD，距视口底部 22px | 状态、时间进度、昼夜和暂停在同一处，删除横跨屏幕的页脚。 |
| 3px 时间进度条 | 取代数字计时，15 秒内逐渐缩短；暂停后冻结并显示“已暂停”。 |
| 羊皮纸底色、1px 深绿边框和小阴影 | 保留复古游戏的纸张质感，减轻界面遮挡感。 |
| 陶土橙主按钮，辅助操作使用深绿 | 日夜保持同一品牌主色，入口有明确优先级。 |
| Pixelify Sans 用于 Logo、标签与数字 | 保留像素气质；中文使用系统黑体以保证阅读。 |
| 中文正文 14–16px，辅助文字至少 12px | 小字仍能阅读，右侧标题弱于村庄主标题。 |
| 一次显示一处人物对话 | 让人物可探索，避免多个气泡争夺注意力。 |
| NPC 悬停、焦点和点击共用自动对话的 Canvas 气泡 | 图一的粗像素边框、单行文字和像素网格保持一致；角色名与对话保留在可访问描述中。 |
| 约 1.2 秒人物交叉淡入，环境色逐渐变化 | 天空、建筑与窗灯平滑过渡；太阳与月亮同步淡入淡出。 |
| 夜间潜入村民家中 | 村民先回屋，两只狼人沿小路先后进门，屋内行动以窗灯熄灭表示，随后出门离开；门框裁切人物，移除屋内点击区域。 |
| 云层缓慢移动，烟囱保持少量烟雾 | 丰富村庄活动，不增加持续闪烁的界面动画。 |
| 按钮按下移动 2px，卡片只淡入 6px | 反馈延续像素风格，动效保持克制。 |
| 手机先展示场景和主入口，再显示档案；HUD 固定于视口底部 | 保留人物观看空间；窄屏 HUD 分两行，页面底部留足滚动空间。 |
| 点击区域使用 Canvas 的同一角色数据与 cover 裁切 | 不同宽高比下人物和可点击位置一致，淡出或消失的角色不留空按钮。 |
| 短宽屏保留更多天空，减少前景裁切优先级 | 避免标题和屋顶争夺空间，人物投影同时适配取景。 |

## 颜色

| 用途 | 色值 |
| --- | --- |
| 羊皮纸 | `#F7F2E6` |
| 深松绿 | `#293F39` |
| 陶土橙 | `#B65330` |
| 草地绿 | `#8DAF79` |
| 夜幕蓝 | `#20334A` |

场景素材保留原有细分颜色；界面强调色限定为陶土橙。夜间只改变场景文字和环境光，档案、按钮与 HUD 保持统一样式。

## 演示边界

首页与开始游戏的交互是本地原型。演示房间明确标记脚本角色，不调用 AI，不进行真实对局和胜负计算。正式游戏需按现有 REST / WebSocket 契约接入后端。
