# AI 观战与游戏回放页面

## 范围与入口

按用户提供的双页参考图实现，沿用经典九人配置。大厅提供两个入口：

- `/watch/demo`：九位 AI 的只读观战演示，左侧对局信息和玩家列表、中间营火桌、右侧当前发言、最近四条发言和决策摘要。
- `/games/demo/replay`：左侧回放信息和 Event 时间线，右侧游戏过程、播放控制、关键事件详情和玩家视角。

两页复用 `VillageScene`、`VillageHeader`、`GameTable`、`PixelAvatar`、`PixelIcon`、`PixelDialog` 和木框资产。回放场景增加可选夕阳天空配色，不影响首页和其他页面默认配色。桌面保留参考图的左右分区，窄屏将游戏过程、信息与时间线按顺序堆叠。设计密度沿用 ENERGY 2 / RHYTHM 2 / MOTION 1。

## 适配层与展示状态

`features/observation/types.ts` 是本地展示类型，不是新增的服务端 schema。只读端口 `ObservationAdapter.get(gameId)` 返回一份示例记录，没有提交行动的方法。

| 字段 | 用途 |
| --- | --- |
| `gameId / roomName / startedAt` | 对局标识与展示信息 |
| `duration / initialPosition` | 播放长度与初始游标，单位秒 |
| `players` | 九席 AI、头像、公开或已授权角色及初始存活状态 |
| `events[].id / version / at` | 事件标识、升序版本、播放位置 |
| `type / title / content / scope` | 事件类型、摘要、正文、展示可见性 |
| `seatNo / recipient` | 发言者或私有记录所属座位 |
| `change` | 已记录的阶段、轮次、出局座位或胜负展示更新 |
| `rationale` | 手工编写并明确标注的示例决策摘要 |

Pinia 容器 `stores/observation.ts` 管理加载、错误、游标、速度、暂停、视角与事件筛选；加载按版本排序。`projectObservation` 从初始玩家和游标之前的事件构建展示状态，倒退时重新计算，因此出局状态可以正确恢复。它不重新执行游戏规则、投票、随机决策或模型调用。胜负只取记录中的结束事件，空记录显示“暂无结果”。

加载使用请求代次，过期响应不能覆盖新路由。页面每 250ms 依据实际经过时间推进播放游标，速度支持 0.5x、1x、2x、4x；到结尾暂停，再次播放从开局开始。离开页面清理计时器、音频与场景，并清空对局状态。非 `demo` 系列 ID 显示未接入提示，不伪造真实对局。

## 操作与边界

- 播放/暂停、上一/下一事件、拖动进度、跳转阶段与日期。手动跳转会暂停播放，到事件边界禁用相应按钮。宽屏观战底栏按参考图收为单行控制，进度仍显示在左侧；手机保留完整进度拖动。
- 时间线按版本排列，可筛选公开、狼人阵营、角色私有或裁判事件；筛选仅改变列表与详情，不改变游戏桌。
- 时间线可切换自动跟随，用上下键、Home、End 移动游标和焦点；座位沿用方向键导航，可打开只读信息。
- 当前事件详情展示类型、版本、时间、可见性、正文与 ID；支持复制 ID、跳到该事件。剪贴板不可用时提示手动选取 ID。
- 回放提供赛后全量、公开记录、指定玩家的展示视角。玩家视角仅列公开、本人私有及所属阵营事件，其他角色标签隐藏。
- 原生弹窗支持 Escape 和焦点归还。全屏与音频失败均提供可读反馈。加载、空列表、无发言、读取失败和无效对局均有对应状态。

## 数据与授权边界

当前两页共用一份已完成 AI 对局的本地脚本记录。观战播放也是该脚本的展示，不连接实时服务器、不调用 AI。示例事件与发言不代表真实模型输出；决策说明不声称是模型私有思维过程。

本地样例包含全部授权演示数据，视角切换只是展示筛选，不能作为正式权限控制。正式观战必须消费服务端认可的观战订阅及可见性投影，不能通过前端选择器获得权限；参与者不能同时取得观战视图。正式回放只使用服务端返回的已授权事件，不缓存其他对局的隐藏信息。

正式适配器映射、登录、REST 版本区间加载、WebSocket 观战订阅、恢复同步与逐块发言均 **TBD，尚未接入**。本次未修改共享 API / WebSocket 契约，也未实现正式 AI 分析页或游戏规则。

## 验证

2026-10-11：`npm test` 共 10 文件、85 项通过；`npm run build` 含 Vue / TypeScript 类型检查通过，90 模块完成构建。新增测试涵盖游标倒退、版本顺序、经典九席、视角筛选、速度、边界、计时器清理、过期请求、时间线键盘、详情、空记录、加载与失败。

浏览器检查两页在 320、390、620、768、1024、1366、1672 宽度无水平溢出、座位卡无相互覆盖。桌面压缩布局另检查独立人物图像与卡牌的遮挡。浏览器完成公开视角、玩家私有视角、事件筛选、阶段跳转、详情与 Escape；读取的控制台无错误或警告。

主要文本对比度用 antislop-human 的计算器验证：辅助字 5.61:1、村民标签 5.88:1、狼人标签 5.20:1、夕阳标题 5.85:1、导航标签 4.93:1、女巫标签 5.59:1。焦点使用明确轮廓，出局同时展示文字/符号。
