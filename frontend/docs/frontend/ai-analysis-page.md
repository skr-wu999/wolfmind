# AI 分析页面

入口：`/games/:gameId/analysis`，本地示例 `/games/demo/analysis`。大厅、AI 观战与游戏回放均提供链接。按用户参考图实现，沿用项目经典九人配置。

## 布局与复用

- 左侧：对局信息、可筛选回合的关键事件时间线。
- 中间：阶段标题、Agent 选择器、九席营火桌与当前分析席位标识。
- 右侧：角色目标、行为风格、策略标签，以及观察、判断更新、候选行动、最终选择四步摘要。
- 下方：阵营胜率、决策时个人存活率、目标判断置信度、候选行动示例评分。
- 底部：全局/阵营/单 Agent 分析视角，章节、进度、速度、前后事件、播放暂停及全屏控制。

复用 `VillageScene`、`VillageHeader`、`GameTable`、`PixelAvatar`、`PixelIcon`、`PixelDialog`、`ObservationControls`、村庄音频和回放投影。新增 `AnalysisMetric` 只负责百分比/分值的可读数值和比例条。桌面三栏；中等宽度两栏；窄屏按游戏桌、策略/决策、对局信息/事件、图表顺序排列，手机座位转为双列。

## 数据与交互

`features/analysis/types.ts` 是前端展示类型，不是新的 REST DTO。`AnalysisSummary` 保存已结束对局标识、默认 Agent、初始游标、示例估计序列和来源说明；`AgentAnalysis` 按席位单独加载角色策略与 `DecisionTrace[]`。每条摘要引用现有已接受发言的 `eventId`、时间、回合和正文，包含观察摘要、判断更新、候选项与最终选择。分析记录不塞进游戏领域事件。

初始打开第 2 天 13:40 的 4 号发言。点击卡牌或选择器暂停播放并加载该席位的分析，成功后聚焦策略标题。发言事件同时跳转时间与对应 Agent；其他事件只移动游标。决策摘要与估计均取不晚于游标的最后一条记录，回退时不会提前展示未来摘要。个人存活与身份判断明确属于所展示决策的时刻。

策略使用该角色可见的信息编写，摘要没有模型私有思维过程。概率是手工编写的示例估计，不是实际模型预测；候选行动显示示例评分（分），不宣称行动造成胜率增长。每页有来源说明。延迟、Token 和没有提供的数值保留 `null`，显示“暂无数据”，不替换为 0。

图表的三个视角改变展示系列：全局包含所有系列；阵营仅显示选中 Agent 所属阵营与候选评分；单 Agent 显示个人存活、目标判断及候选评分。数据表提供对应视角的完整名称与数值，避免仅靠色条或截短的标签理解信息。

## 状态与访问边界

- 页面加载：独立加载反馈；汇总或回放失败：错误、重试、本地示例和返回大厅。
- Agent 加载：保留现有内容并显示忙碌状态；失败保留当前 Agent，提示仍显示哪个座位，重试失败的目标。
- 无摘要：仍显示策略资料；尚未到达首次摘要时提供显式跳转按钮；无事件或估计有相应空状态。
- 汇总、Agent 和页面加载均有请求代次保护；晚到、不同对局/席位以及离开页面后的响应不覆盖当前状态。
- 仅接受 `COMPLETED` 的分析汇总；访问拒绝与未结束状态显示限制反馈，不渲染角色桌。当前完全是已标注的赛后本地示例，不能用客户端过滤代替真实权限校验。
- 时间线支持上下方向键和 Home/End；座位沿用方向键导航。Agent 切换有焦点反馈，详情弹窗支持 Escape 与焦点返回。播放使用独立时钟，卸载时清理计时器和状态。
