# 游戏大厅本地原型

实现日期：2026-10-11。范围：用户提供的大厅参考图、房间列表、创建房间、加入游戏。此文记录前端原型，不批准新的游戏规则或共享 API。

后续房间座位预览已升级为[房间等待页](room-waiting-page.md)，支持玩家/AI 展示和准备。本页下方验收记录为大厅首次实现时的证据。

## 布局和复用

桌面保留参考图的像素村庄背景、顶部导航、左侧大厅标题、木框列表和右侧上下两个操作面板。列表带树形标识、四个筛选和六行房间；侧栏带屋顶狼、小屋插画、创建按钮和房间号输入。底部复用原昼夜控制。

`VillageScene` 从原首页抽出 Canvas 场景及人物交谈，管理动画帧、尺寸观察和减少动态效果设置；`VillageHeader`、`VillageHud` 和音效组合函数由首页、大厅、房间预览共享。`VillageIllustration` 调用原绘制器内的房屋、树、云、围栏函数；没有另外导入村庄图片。新木框和屋顶狼使用代码 SVG，图标扩展原 `PixelIcon`。

900px 以下侧栏排到列表下方，620px 以下房间行改为卡片、操作面板纵向排列。所有内容可纵向滚动，页面底部预留 HUD 空间。

## 页面流程

| 入口 | 行为 | 结果 |
| --- | --- | --- |
| 首页开始游戏 | 导航 | `/lobby` |
| 全部 / 公开 / 进行中 / 等待中 | 本地筛选、回到第 1 页 | 每页最多 6 间，超出时显示分页 |
| 刷新列表 | 调用适配器 list | 载入提示；失败保留上次列表，显示重试 |
| 创建房间 | 弹窗输入 1–24 字名称，选择公开或凭号加入 | 创建九人房、创建者占 1 号座，跳转 `/rooms/:roomId` |
| 列表加入 / 输入房间号 | 调用适配器 join | 占第一个空位，展示自己的座位 |
| 错误房间号 / 已开始 / 满员 | 适配器拒绝 | 可读反馈，不增加人数 |
| 再次加入同房间 | 返回原座位 | 不重复增加人数 |
| 复制房间号 | Clipboard API | 成功反馈；不可用时提示手动复制 |
| 离开房间 | 释放自己的座位 | 返回大厅并刷新人数 |

弹窗使用原生 `dialog`，自动聚焦输入、限制焦点于弹窗、支持 Escape 和焦点恢复。错误使用 `role=alert` 与关联字段描述。加载、空列表、无效房间均有明确状态和返回入口。按钮请求期间禁用；列表响应版本检查避免旧请求覆盖新数据，离开页面后不再因异步结果跳转。

## 本地数据边界

`RoomAdapter` 暂时只定义 `list/get/create/join/leave` 的前端异步接口，`createMockRoomAdapter` 为其本地实现。`DemoRoomSummary` 是展示模型，不是 REST 契约的副本。

六个初始房间使用参考图名称；人数和容量遵循已批准的经典九人基线。状态只有等待和进行中。列表摘要含房间号、名称、描述、模式展示名称、人数、容量、状态、加入方式、可加入标记及插画类型；不含座位身份或秘密角色。房间预览只展示脚本村民名称、空位和“你”，不分配角色或触发对局。

本地状态存储键为 `wolfmind.demo.rooms.v1`，使用 `sessionStorage`，不可用时回退内存。损坏的数据产生反馈，不静默覆盖。凭号加入用于演示公开列表筛选，不能提供真实身份授权或房间隐私保护。创建后离开不会删除房间，人数变为零；这只是本地演示生命周期。

房间页明确标注本地预览，未实现登录、准备、AI 补位、开局、真实观战、WebSocket 或在线多人同步；进行中的示例房间按钮禁用。
